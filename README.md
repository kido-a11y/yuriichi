# ゆりいち サイト提案

農産物直売所ゆりいちの静的サイトモックです。

## 公開

1. このフォルダーの内容をGitHubリポジトリの `main` ブランチに配置します。
2. リポジトリの Settings → Pages → Source で GitHub Actions を選びます。
3. Actions の Publish website to GitHub Pages を実行します。

`dist/` が公開対象です。ビルドや環境変数は必要ありません。
既存の画像参照を維持し、使用中の画像はWebPで軽量化しています。
商品・生産者・イベント情報には提案用の仮情報を含みます。
